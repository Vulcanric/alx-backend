# 0x03. Queuing System in JS
**`Back-end`**  **`JavaScript`** **`ES6`** **`Redis`** **`NodeJs`** **`ExpressJS`** **`Kue`**<br>

## Description
This project is part of the ALX Back-end specialization curriculum and is done to get hands-on experience with the following:
* Running a Redis server on my local machine.
* Running simple operations with the Redis client.
* Using Redis client with ***NodeJS*** for basic operations.
* Storing hash values in Redis.
* Dealing with ***async*** operations with Redis.
* Using ***Kue*** as a queue system.
* Building a basic ***Express*** app interacting with a Redis server, and
* Building a basic ***Express*** app interacting with a Redis server and queue.
